# Use Case Diagrams

This folder contains UML Use Case diagrams for the Smart Plug AI system.

## Expected Files

The following diagram files will be added to this directory:

- **1.1_System_Use_Case.vpp** - High-level system use case diagram showing all actors and main use cases
- **1.2_User_Use_Case.vpp** - Detailed user-focused use cases for homeowners and facility managers
- **1.3_Admin_Use_Case.vpp** - Administrative and security operations use cases

## Diagram Contents

These diagrams will illustrate:

- **Primary Actors**: Homeowner, Facility Manager, System Administrator, Security Auditor, IoT Device, Mobile Application, Web Dashboard
- **Authentication & Security Domain**: Authenticate with 2FA/MFA, Manage User Profile, Review Security Audit Logs, Configure Security Policies
- **Device Management Domain**: Pair New Device (QR + Challenge-Response), Monitor Real-time Power Usage, Control Device Remotely, View Device Status
- **Data & Analytics Domain**: View Historical Analytics, Generate Usage Reports, Export Data, Set Energy Usage Alerts
- **System Administration Domain**: Manage User Accounts (RBAC), Configure System Settings, Monitor System Health, Update Firmware (Secure OTA)
- **Security Operations Domain**: Respond to Tamper Alerts, Review Device Attestation, Manage Security Certificates, Investigate Security Incidents

## Tools

- **Primary Tool**: Visual Paradigm Community Edition (free for students)
- **Backup Tool**: Diagrams.net

## Notes

All diagrams follow UML 2.5 notation standards and incorporate bank-grade security features of the Smart Plug AI platform.
